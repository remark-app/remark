# Remark

Комментарий к любому месту экрана Mac: отметьте место, напишите или надиктуйте, что нужно сделать, и комментарий со скриншотом уйдёт в чат Claude Code или Codex.

Только для Mac, macOS 14 и новее (Apple silicon и Intel).

## Установка

Откройте утилиту Терминал, вставьте команду и нажмите Enter:

```bash
curl -fsSL https://github.com/remark-app/remark/releases/latest/download/install.sh | bash
```

Та же команда обновляет Remark. Скрипт `install.sh` лежит рядом с приложением в [последнем выпуске](https://github.com/remark-app/remark/releases/latest): его можно прочитать перед запуском.

## Что Remark делает с вашими данными

- Снимки экрана и тексты комментариев хранятся только на вашем Mac, в папке `~/Remark`, и удаляются через 7 дней (срок меняется в настройках).
- Remark сам ничего не отправляет по сети. Единственные обращения в сеть: проверка обновлений раз в сутки (с этого репозитория) и скачивание модели надиктовки при первом включении (с huggingface.co). Надиктовка распознаётся на вашем Mac.
- Комментарий со скриншотом попадает в тот чат Claude Code, Codex или Claude, который выбрали вы: дальше он живёт по правилам этого сервиса.
- Для работы Remark просит разрешения на запись экрана и универсальный доступ; без них он не сможет снять экран и вставить комментарий в чат.
